AutoCobwebRemove 1.0.0

Dzialanie:
- Reaguje tylko na pajeczyny (COBWEB) postawione przez graczy.
- Czeka 15 sekund.
- Pokazuje animacje pekania przez okolo 1 sekunde.
- Usuwa pajeczyne, jesli nadal znajduje sie w tym samym miejscu.
- Nie usuwa innych blokow.

Wymagania:
- Paper 1.21.11
- Java 21
- Maven do zbudowania projektu

Budowanie:
1. Otworz terminal w folderze projektu.
2. Uruchom: mvn package
3. Gotowy plik bedzie w: target/AutoCobwebRemove-1.0.0.jar

Instalacja:
1. Wylacz serwer.
2. Wgraj JAR do folderu plugins.
3. Uruchom serwer ponownie.

Uwaga:
To jest projekt z kodem zrodlowym, nie skompilowany JAR.
Animacja pękania jest wysylana klientom w zasiegu 64 blokow.
